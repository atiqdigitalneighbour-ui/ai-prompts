# Master Off-Page SEO Workflow
## Web 2.0 | Article Submission | Guest Posts | AI Content Creation

Version: 1.0

## Objective

Create high-quality off-page content that:
- Improves topical authority
- Builds contextual backlinks
- Supports internal pages
- Looks natural
- Scales with AI-assisted production

## Required Inputs

- Target URL
- Primary keyword
- Secondary keywords
- Semantic keywords
- Internal linking sheet (project pages)
- Off-page profile sheet
- Existing backlink inventory

## Workflow

### 1. Collect Inputs
- Read target URL.
- Extract page intent.
- Import keywords and destination URL.
- Load internal linking opportunities from project pages.
- Load profile links from the off-page sheet.
- Avoid duplicate properties and backlinks.

### 2. SERP & Intent Analysis
- Analyze search intent.
- Review competing pages.
- Extract entities, FAQs, semantic terms, and content gaps.

### 3. Build Content Plan
- Choose a unique angle.
- Map H1/H2/H3 structure.
- Assign primary and supporting keywords naturally.

### 4. Content Creation
#### Web 2.0
- 800–1200 words

#### Article Submission
- 1000–1500 words

#### Guest Post
- 1500–2500 words

Requirements:
- Human-readable
- E-E-A-T focused
- Unique structure
- Natural keyword usage
- Actionable examples

### 5. Internal Linking
Use project pages to insert 2–5 relevant internal links with varied anchors.

### 6. Backlink Placement
Insert one contextual backlink to the target URL using diversified anchor text.

### 7. External References
Include 2–3 authoritative references when appropriate.

### 8. SEO Optimization
Include:
- SEO title
- Meta title
- Meta description
- URL slug
- Image ALT text
- FAQs
- CTA

### 9. QA Checklist
- Original content
- Grammar checked
- Unique introduction/conclusion
- Correct anchors
- Internal links
- External links
- Metadata complete

### 10. Tracking
Record:
- Platform
- Published URL
- Target URL
- Anchor
- Keyword
- Status
- Indexing

## AI Content Guidelines

Inspired by the Unified AI Blog Workflow:
- Start with search intent.
- Cover the topic comprehensively.
- Use topical entities.
- Write with E-E-A-T.
- Avoid repetitive AI phrases.
- Generate multiple title/meta options.
- Suggest internal links from project pages.
- Use profile links from the off-page sheet.
- Keep every article unique.

## Deliverables
- SEO Title
- Meta Title
- Meta Description
- Slug
- Full Article
- FAQ
- Internal Link Suggestions
- External Link Suggestions
- Image Suggestions
- Anchor Recommendation
- Publishing Checklist

## Golden Rules
- Never duplicate content.
- Never reuse introductions.
- Diversify anchors.
- Link contextually.
- Keep content valuable.
- Update the tracking sheet after every publication.
